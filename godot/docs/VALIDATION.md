## 既有输入与规则回归

- 问题定位：此前截图的运行工具栏选中「2D」，Godot 会在该模式禁用游戏输入；应选择左侧「输入」。游戏内嵌运行时加入提示，并提供 `启动游戏.command` 独立启动入口。
- 对五种分辨率注入窗口坐标的鼠标输入，验证三个阵营、换地图、教学、读档和开始；通过 Input 注入触摸验证普通按钮。遍历桌面 / 窄屏主页面的可用按钮，确认点击中心没有被其他控件拦截。
- 验证四种战术、配置提交、拆分滑块、保存 / 读取、取消 / 确认结束回合、重开。测试 UI 的存档目录明确指向临时缓存。
- 窗口缩放保留弹窗和未提交文字；选中指令自动显示星图；进攻模式可先选己方攻击编队。
- 修复太空舰队第二次移动被误判为已经驻守、重复建造叠加属性、更换 / 轰炸设施后旧收入保留；无效指令参数被拒绝且不扣资源。
- 修复触摸取消 / 窗口失焦后的残留拖动；装饰标题与遮罩不会抢走按钮事件。
- 新增 12 类损坏但可解析的 JSON 存档测试，拒绝错误类型、缺失结算字段、无效模块等，并保留当前战局。
- 下拉菜单验证鼠标打开与选择信号绑定；原生菜单项的操作系统级键鼠分发未自动验证。本轮没有桌面辅助权限，未代替用户点击编辑器「输入」开关，也未验证手机真机。

## 交付范围与边界

这是 Godot 2D 原生项目，不是 HTML/WebView 版本。保留参考内容结构，按最新要求整体更换画风，采用响应式布局。复杂系统采用轻量回合制规则，AI 使用启发式决策，不代表高级竞技 AI。

已验证本机桌面运行及模拟触摸事件，**未验证手机真机、Android / iOS 安装包或其他操作系统**。导出独立安装包需要对应平台模板、SDK 与签名。请通过 `project.godot` 导入后按 F5。

原始提示词保留在 `docs/original-brief.txt`，游戏内「世界观与原始设计内容」可以阅读全文。原始网页的技术约束以 Godot 本地方案替代，见 README。
