# 星门纪元：银河分裂 · Godot 2D 对照清单

以原始长提示词为玩法依据，沿用参考截图的主要内容结构。按 2026-10-17 的最新要求，整体视觉改为科技感深蓝舰桥界面，减少装饰，保留所有游戏操作控件的说明。技术栈为 Godot 4 / GDScript。2026-10-24 增加家园、副本、战舰、补给与可选 ENet 真人直连单挑；单人战役继续支持离线。以下旧清单中的离线描述适用于单人战役。

## 参考图布局

- 开场：离线战略桌游、星门纪元 / 银河分裂、星图代码、换一组、三阵营选择、开启星门、新手教学。
- 战局：新手指南、标题、重开；剩余行动 / 我的星球 / 信用点 / 材料；战争周期；五色阵营图例；圆形星球与星门线路。
- 战术指令：扩张、进攻、增援、舰队调度；目标高亮、失败原因；阵营被动、主动技能和第四回合技能。
- 后续：外交频道、舰队工坊、战役存档、结束本轮、行动序列、星球信息。补充原提示词的太空舰队、星门、资源点、战报。
- 窗口适配：桌面开场双栏、窄屏单栏，开始操作固定在页底；标题按实际分配的宽和高限制字号，星图按两个方向统一缩放。改变窗口高度同样触发布局更新，不清空战役。

## 新画风与说明

近黑深蓝背景、海军蓝面板与钢青细线统一覆盖开场、HUD、战术指令、工坊、外交、存档、教程、弹窗与项目图标。三个阵营使用独立绘制的线条徽记，选择区减少整圈边框；字体粗细、按钮高度与资源栏收紧。战术指令用原生线图标，桌面双列、窄屏单列。星图移除云层、球体渐变和层叠光晕，改用平面星球、首都双环、目标角框和稀疏星点；边缘刻度根据世界坐标换算，平移缩放同步变化，回放小星图省略刻度。未知及旧情报仍只使用观察者数据，不泄露隐藏兵力。保留舰船移动、炮火和占领动画，不重写旧存档的舰队自定义涂装。保持 2D 与离线运行。

普通按钮提供可见副标题和悬停详情；卡片保留内嵌说明。所有游戏创建的按钮与输入控件注册具体说明。说明模式在执行回调之前拦截点击，支持触摸与 F1，不会创建战役、保存配置或删除文件；说明浮层独立于原弹窗，不丢失编辑内容。窄屏较长的副标题可省略显示，完整内容始终可通过说明模式查看。

## 玩法验收

本轮放大舰队标记约两倍，绘制、点击半径及回放移动符号统一缩放；驻军标记使用屏幕空间间距以避开星球中心。迷雾的空心舰标、原有涂装和两种舰队图标继续有效。

配乐《深蓝守望》由随附 Python 源码合成旋律、和弦和音色，输出 80 秒立体声 Ogg。Godot 单独的 AudioStreamPlayer 节点跨页面重建连续播放，提供音量渐变、暂停和整曲循环。底部音乐设置支持说明模式与触摸，偏好写入独立 `audio.cfg`，不更改战役存档结构。游戏运行不依赖 Python、ffmpeg 或网络。

1. 三个可选人类阵营、独立 AI、外星远征军；相同种子重现地图。
2. 九种模式：标准战争、外星入侵、星门争夺、护航、残局生存、外交竞赛、随机灾变、沙盒、三章连续战役。
3. 星球属性、首都、资源、好感、建筑、围困；星门占领、封锁、破坏、修复。
4. 六种舰队；驻守 / 太空；鼠标和触摸拖动；移动预估、路径颜色、确认菜单。
5. 相遇、合并、限时增援、滑块拆分、模块交换；敌方开战 / 侦察 / 避让 / 威慑 / 停火。
6. 突袭、围困、轰炸、封锁、策反、诱敌；占领后的直接统治、自治、保护、掠夺、重建。
7. 购买 / 升级 / 改名 / 颜色 / 图标 / 类型 / 模块、等级和阵营限制。
8. 五种资源、好感 -100…100、外交协议与交易、援军、开放星门、领地交换、背叛。
9. 回合收入、AI 行动、战争事件、外星入侵、模式胜负与沙盒设置。
10. 14 步短句教程、本地多槽存档、时间、自动存档、删除确认、完整状态恢复。

## 侦察与连续战役扩展

`campaign_systems.gd` 提供可序列化的观察者快照，星图、星球面板、舰队列表和回放使用快照；规则结算保留真实战区。基础视野只识别归属与位置，侦察舰 / 模块识别兵力，主动扫描有期限与暴露代价。外交提供带时间戳的报告，不变成永久追踪。己方损失始终可见；远处敌军变化不会通过战报和回放泄露。

帝国守备、联盟通商、混沌突袭分别改变加固、增援、目标排序、拦截优先级和外交门槛。出击移动真实舰队并扣除损伤，不在原地保留同一份兵力。敌方每轮两次行动，消费己方资源；外星入侵仍按模式脚本出现。

每轮保存初始可见星图和按决策顺序生成的事件快照。回放使用独立只读星图，移动 / 炮火 / 占领动画不改变战役状态；最多保留最近一轮 64 条事件。每次玩家成功行动也可播放短反馈。

剧情为固定时间点触发的六种分支事件，未处理时暂缓后续事件。费用检查先于修改，已完成事件记录防止重复领取。连续战役三章提供占领并守住目标、守都生存、夺取敌都任务。换章创建新战区后替换己方初始驻军，保留幸存舰队及其配置、资源与剧情旗标，运输船是否获救影响第二章补给。

版本 3 存档将情报、指挥官、剧情、回放和章节一起保存，继续保存 RNG 状态；兼容版本 2 的完整战役。扩展字段在提交加载前校验，损坏数据不改变当前战局。

## Godot 适配

`index.html` / HTML / CSS / JS / localStorage 属于原网页技术要求，按后续“Godot 2D”要求替换为 `project.godot` / 场景 / GDScript / `user://` JSON。Android WebView 61 不适用于原生 Godot；需安装 Godot 官方导出模板后导出移动平台。单人战役不依赖网络；真人单挑按需通过 ENet UDP 直连。

## 操作与存档

点击指令再点击星球；选中己方舰队后拖到星球、舰队、星门或空白太空，在确认菜单结算。空白拖动平移，滚轮 / 加减缩放，触屏双指缩放，长按舰队打开菜单。菜单外的按钮不应移动地图。

新版本使用 `user://campaign_slot_1.json` 到 `campaign_slot_3.json` 和 `campaign_auto.json`，不会覆盖旧版不完整的 `star_gate_save.json`。


## 2026-10-24 新玩法实现

- `frontier_systems.gd`：三个战力判定副本，消耗行动与燃料，每轮三次；胜利获得材料、星币与阵营功勋，失败无奖励。
- 家园四种建筑最高五级，按回合自动产出；指挥中心提高副本战力。阵营功勋用于军需兑换与军衔显示。
- 四种战舰可抽取、直接建造、星币直购、升级、升星、选择出战、部署为真实星图舰队；部署遵守阵营编制上限，保留最后一艘当前出战舰。
- 三个抽奖卡池支持单抽/十连，使用星币并公开各自 SSR/SR/R/材料概率；连续 19 次未得 SSR 后下一抽保底，重复舰体自动升星并保存 RNG。
- 福利按轮次领取，副本累计通关次数解锁远征里程奖；福利、家园和副本都能增加星币、材料或燃料。
- 新字段按完整结构校验，损坏存档不改变当前战局；旧存档自动补齐。连续战役换章保留家园、机库、功勋与保底。
- `duel_network.gd`：真实双人 ENet UDP；双方独立选择阵营，使用对等旗舰，房主验证发送者、轮次、操作版本、能量与技能次数，再广播结果；口令、版本校验和连接超时/断线处理。
- 真人对局独立于本地战役，不提供账号、跨网自动匹配、战役多人同步、断线重连或排行榜。公网直连需网络配置，不包含已部署的中心服务器。
