请制作一款纯前端、离线运行的科幻战略桌游网页游戏。

游戏名称：
《星门纪元：银河分裂》

一、项目定位

这是一款支持桌面端鼠标操作和移动端触摸操作的科幻银河战争桌游。

玩家可以：

- 选择不同阵营。
- 控制星球、星门和舰队。
- 创建、购买、升级和配置舰队。
- 将舰队驻守在星球，也可以让舰队脱离星球，在太空中自由移动。
- 通过鼠标拖动或星门移动舰队。
- 遇到友方舰队时合并、增援或拆分。
- 遇到敌方舰队时选择开战、避让或暂时共存。
- 调动舰队攻击星球、驻守星球或争夺星门。
- 通过外交、好感度、交易和结盟影响其他势力。
- 面对随机战争事件和强大的外星系入侵。

游戏必须简单易上手，但包含足够的战略深度。

二、世界观

公元 4729 年，人类研发出星门传送技术，通过固定星门枢纽实现跨星域瞬间移动。

银河帝国依靠统一的星门能源、科技共享和星权均等法案，统一了大半个银河系。帝国消除了不同星球之间的科技与资源差距，但也收回了各星球的军事、资源、星门和行政权。

原有贵族、地方统治者和边境星球逐渐反抗帝国统治。数十颗边境星球破解并复制了帝国星门技术，成立“自由星域联盟”，以星球自治和地方主权为口号向帝国宣战。

银河内战持续一百年后：

- 帝国只保留核心星域，占据约 30% 的宜居星域。
- 自由星域联盟占据约 50% 的银河星域。
- 剩余 20% 成为破碎星域，由盗匪、流亡军队、商会和中立星球控制。

当前时代为“星门破碎纪元 100 年”。

银河主要势力：

1. 残余正统人类帝国

定位：防守反击、高科技、精锐舰队。

特点：

- 星球数量较少。
- 科技和资源质量最高。
- 防御设施强。
- 舰队数量有限，但单体战斗力高。
- 星门防御能力强。
- 不容易被策反。

弱点：

- 扩张成本高。
- 远程调动成本高。
- 舰队数量上限较低。
- 不适合长期人海消耗战。

2. 自由星域联盟

定位：快速扩张、策反渗透、人海战术。

特点：

- 星球数量多。
- 舰队生产速度快。
- 扩张和占领成本低。
- 可以策反敌方边缘星球。
- 可以同时从多个方向进攻。

弱点：

- 内部派系复杂。
- 好感度容易下降。
- 可能发生内耗、叛乱和资源损失。
- 单支舰队的质量低于帝国。

3. 中立混沌势力

定位：游击、交易、掠夺、背刺和残局得分。

组成：

- 星际盗匪集团。
- 流亡帝国残军。
- 独立科技商会。
- 破碎星域中立星球。
- 星门流浪者。

特点：

- 可以与任何阵营临时结盟。
- 擅长伏击、劫掠和资源交易。
- 可以在不同势力之间反复改变立场。
- 拥有较高的远程机动能力。

弱点：

- 没有固定安全核心。
- 正面作战能力较弱。
- 被多个阵营集火后容易崩盘。

4. 外星系远征军

定位：随机出现的强大共同敌人。

特点：

- 战斗力显著高于三大人类势力。
- 可能从未知星门进入银河。
- 可以占领中立星球和边境星球。
- 拥有特殊舰队和未知科技。
- 不完全遵守普通外交规则。

玩家可以与其他阵营暂时停战，共同抵抗外星军。

三、星图系统

星图由以下元素组成：

- 星球。
- 星门。
- 星门线路。
- 资源区域。
- 破碎星域。
- 未知空间。
- 外星入侵点。
- 太空中的舰队。

星球属性包括：

- 星球名称。
- 所属阵营。
- 星球类型。
- 资源产出。
- 防御值。
- 星门数量。
- 驻守舰队。
- 是否为首都。
- 是否拥有特殊建筑。
- 是否处于混乱、封锁或入侵状态。

星门规则：

- 普通舰队可以通过相连星门移动。
- 星门可以被占领、封锁、破坏或修复。
- 某些舰队拥有远程移动能力。
- 远程移动不要求星门相连，但需要消耗更多行动点或资源。
- 星门被封锁后，普通舰队无法通过。
- 外星系舰队可以使用未知星门进入地图。

四、舰队系统

舰队不一定必须停留在星球上。

舰队有两种状态：

1. 驻守状态

舰队停留在星球上，可以：

- 防守星球。
- 生产资源。
- 修复舰队。
- 参与星球攻击。
- 进行升级和补给。
- 保护星门和建筑。

2. 太空状态

舰队位于星球外的地图空间中，可以：

- 被玩家通过鼠标拖动。
- 通过星门移动。
- 调查未知区域。
- 追踪敌方舰队。
- 拦截敌方运输线。
- 进攻其他舰队。
- 攻击星球。
- 前往星门或资源点。
- 脱离战场或支援友军。

太空舰队必须在地图上以清晰的图标、颜色、数量和舰队名称显示。

五、舰队移动和鼠标操作

桌面端操作：

1. 点击或拖动己方舰队。
2. 拖动舰队到目标位置。
3. 目标可以是：
   - 己方星球。
   - 友方舰队。
   - 敌方舰队。
   - 敌方星球。
   - 星门。
   - 空白太空区域。
   - 资源点。
4. 松开鼠标后显示行动确认菜单。
5. 玩家选择移动、攻击、驻守、合并、增援或拆解。

移动规则：

- 通过星门移动消耗较少资源。
- 普通太空移动消耗行动点。
- 远距离移动需要燃料或信用点。
- 敌方控制区域会产生移动风险。
- 某些舰队拥有远程移动、隐匿或高速移动能力。
- 不能移动到被完全封锁的空间区域。
- 移动时必须显示预计消耗、距离、风险和到达时间。

移动状态提示：

- 蓝色路径：安全移动。
- 黄色路径：需要消耗额外资源。
- 红色路径：可能进入敌方控制区域。
- 紫色路径：未知或外星区域。
- 虚线路径：远程移动。
- 发光节点：可以驻守、攻击或合并的目标。

移动端操作：

- 使用触摸拖动舰队。
- 长按舰队显示操作菜单。
- 点击目标区域确认路径。
- 双指缩放星图。
- 单指拖动地图。
- 不依赖鼠标悬停实现核心功能。

六、友方舰队相遇机制

当舰队移动到友方舰队附近时，弹出选择菜单：

1. 合并舰队

- 两支舰队合并成一支大型舰队。
- 总舰队数量相加。
- 保留主舰队类型。
- 如果类型不同，显示混合舰队。
- 混合舰队可以重新配置，但需要消耗材料。

2. 增援舰队

- 不合并编制。
- 一支舰队为另一支舰队提供临时战力。
- 增援持续若干回合。
- 增援舰队仍然可以独立行动。
- 增援结束后返回原来的编制。

3. 拆解舰队

- 将一支大型舰队拆成两支或多支舰队。
- 玩家可以拖动滑块设置拆分数量。
- 每支舰队至少保留 1 个单位。
- 拆解需要消耗少量行动点。
- 拆解后可以执行不同任务。

4. 交换舰队模块

- 两支友方舰队可以交换侦察、护盾、攻击或运输模块。
- 需要消耗材料或情报。
- 不同阵营拥有不同模块限制。

七、敌方舰队相遇机制

当己方舰队遇到敌方舰队时，弹出选择：

1. 立即开战

- 进入舰队战斗界面。
- 根据舰队数量、类型、等级、地形和支援计算结果。
- 胜者占据当前位置。
- 失败方撤退、受损或被消灭。

2. 观察和侦察

- 不立即开战。
- 查看敌方大致数量、类型和等级。
- 需要消耗情报。
- 侦察可能暴露己方舰队位置。

3. 避让

- 立即移动到附近空间。
- 消耗额外行动点。
- 如果对方拥有拦截能力，避让可能失败。

4. 威慑

- 通过外交、舰队规模或阵营声望迫使敌方后退。
- 成功率受好感度、舰队差距和阵营关系影响。

5. 暂时停火

- 允许双方暂时不战。
- 可以建立临时通行权。
- 对方可能在未来撕毁协议。

八、舰队攻击星球

舰队可以驻守星球，也可以从太空攻击星球。

攻击星球流程：

1. 选择己方舰队。
2. 拖动到敌方星球。
3. 选择“攻击星球”。
4. 查看敌方驻守舰队、防御建筑、星门状态和预计战果。
5. 选择直接攻击、围困、轰炸、策反或撤退。
6. 结算战斗。

攻击方式：

- 直接突袭：快速但伤亡较大。
- 围困：降低敌方资源产出和防御。
- 星门封锁：切断增援和补给。
- 轨道轰炸：破坏建筑，但会降低星球好感度。
- 策反行动：消耗情报或影响力。
- 诱敌出击：让敌方舰队离开驻守位置。

攻击成功后：

- 占领星球。
- 夺取资源。
- 接管星门。
- 处理当地好感度。
- 选择驻守、掠夺、自治或重建。

九、舰队类型

1. 突击舰队

- 进攻舰队和敌方舰队时攻击力高。
- 适合远程突袭和突破。
- 防守星球能力一般。
- 不擅长长期驻守。

2. 守卫舰队

- 驻守星球和星门时防御力高。
- 可以建立护盾和拦截区。
- 远程移动速度慢。
- 不适合追击敌人。

3. 开拓舰队

- 占领中立星球效率高。
- 建造资源点和前线基地速度快。
- 正面战斗较弱。
- 可以降低新领地的不满度。

4. 劫掠舰队

- 擅长偷袭运输线、资源点和弱小舰队。
- 远程移动成本低。
- 防御力较弱。
- 适合中立混沌势力。

5. 侦察舰队

- 移动速度快。
- 可以探索未知区域。
- 可以侦察敌方舰队。
- 不适合正面开战。

6. 运输舰队

- 携带材料、信用点、燃料和补给。
- 可以支援其他舰队。
- 战斗力很低。
- 被击毁后会损失资源。

十、舰队升级和配置

玩家可以自定义舰队：

- 舰队名称。
- 舰队类型。
- 舰队颜色。
- 舰队图标。
- 主武器。
- 护盾模块。
- 引擎模块。
- 侦察模块。
- 运输模块。
- 维修模块。
- 隐匿模块。

配置限制：

- 每支舰队拥有有限模块槽位。
- 强力模块需要更高等级。
- 配置完成后需要消耗材料。
- 重新配置需要时间或信用点。
- 不同阵营拥有不同专属模块。

升级方向：

- 攻击力。
- 防御力。
- 移动速度。
- 星门移动效率。
- 远程攻击能力。
- 侦察范围。
- 运输容量。
- 维修速度。
- 撤退成功率。
- 外交威慑力。

十一、资源系统

游戏至少包含：

- 信用点：购买舰队、交易和外交。
- 材料：建造、升级、维修和改装。
- 情报：侦察、策反、远程攻击和外交。
- 燃料：太空移动、远程调动和高速撤退。
- 声望：影响外交和中立星球态度。

资源来源：

- 星球产出。
- 资源星球。
- 贸易路线。
- 战争事件。
- 掠夺敌方运输舰。
- 占领外星遗迹。
- 完成任务。
- 外交交易。

十二、好感度系统

每个阵营、星球和中立势力都有好感度。

好感度范围：

- -100：敌对。
- -50：紧张。
- 0：中立。
- 25：友好。
- 50：盟友。
- 80：深度合作。

影响好感度的行为：

- 保护星球。
- 赠送资源。
- 完成援军请求。
- 避免攻击平民星球。
- 遵守停战协议。
- 破坏敌方补给线。
- 掠夺中立星球。
- 轨道轰炸。
- 撕毁外交协议。
- 背刺盟友。
- 协助抵抗外星入侵。

好感度影响：

- 是否愿意交易。
- 是否愿意结盟。
- 是否提供舰队支援。
- 是否开放星门通行权。
- 是否允许驻军。
- 是否接受策反。
- 是否在战争中保持中立。
- 最终胜利评分。

星球占领后，玩家可以选择：

1. 直接统治：资源高，但好感度下降。
2. 自治管理：资源较低，但稳定性高。
3. 保护协议：获得当地支持，但需要持续投入。
4. 掠夺开发：短期资源高，长期会引发叛乱。
5. 重建星球：消耗材料，提高好感度和产出。

十三、外交系统

玩家可以：

- 提出停战。
- 请求舰队支援。
- 请求开放星门。
- 进行资源交易。
- 交换情报。
- 共同攻击外星敌人。
- 交换占领区。
- 建立保护协议。
- 提议临时联盟。
- 宣布背叛。
- 取消外交协议。

外交结果受到以下因素影响：

- 当前好感度。
- 阵营关系。
- 玩家声望。
- 双方资源差距。
- 外星威胁程度。
- 是否遵守过协议。
- 当前军事力量。

十四、游戏模式

至少实现以下模式：

1. 标准银河战争

- 三阵营争夺星球。
- 占领敌方首都或最终积分获胜。

2. 外星入侵模式

- 外星远征军会持续增强。
- 三方需要决定内战还是合作。
- 击败外星军后进行最终结算。

3. 星门争夺模式

- 地图上有多个关键星门。
- 控制星门可以获得行动和资源优势。
- 最先控制指定数量星门的阵营获胜。

4. 护航运输模式

- 保护运输舰队到达指定星球。
- 敌方可以拦截运输路线。
- 成功护航获得大量资源。

5. 残局生存模式

- 初始资源很少。
- 每轮出现更强敌人。
- 坚持指定回合或完成目标即可胜利。

6. 外交竞赛模式

- 通过好感度、协议和盟友数量获得分数。
- 可以通过和平方式获胜。

7. 随机灾变模式

- 每轮随机发生星门崩塌、资源枯竭、叛乱或外星灾害。
- 地图和规则会不断变化。

8. 沙盒模式

- 自由设置回合数、资源、舰队数量、外星入侵概率和阵营关系。
- 不设固定胜利条件，允许玩家自由实验。

十五、新手指南

必须在游戏中提供分步骤教学：

1. 选择阵营。
2. 认识星球、星门和舰队图标。
3. 选择行动类型。
4. 点击己方星球或太空舰队。
5. 拖动舰队到地图目标。
6. 通过星门移动舰队。
7. 遇到友方舰队时选择合并、增援或拆解。
8. 遇到敌方舰队时选择开战、侦察或避让。
9. 选择驻守星球或攻击星球。
10. 购买、升级和配置舰队。
11. 查看资源和燃料消耗。
12. 通过外交提高好感度。
13. 外星入侵时请求盟友支援。
14. 占领首都或完成模式目标。

新手指南使用短句和图标，不要要求玩家阅读长篇规则。

十六、存档系统

使用 localStorage 实现本地存档。

存档内容包括：

- 游戏模式。
- 地图种子。
- 当前回合。
- 所有星球状态。
- 太空舰队坐标。
- 舰队数量。
- 舰队类型。
- 舰队等级。
- 舰队模块。
- 舰队移动状态。
- 信用点。
- 材料。
- 情报。
- 燃料。
- 声望。
- 所有阵营好感度。
- 外交协议。
- 外星入侵状态。
- 战争事件。

必须提供：
