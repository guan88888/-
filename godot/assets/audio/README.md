# 深蓝守望

为《星门纪元：银河分裂》制作的原创程序合成配乐，不使用现成歌曲、录音或采样素材。

- 文件：`deep_blue_watch.ogg`，Ogg Vorbis、44.1 kHz、立体声。
- 时长：80 秒；72 BPM、24 小节，D 小调氛围。
- 编制：缓慢合成和弦、圆润低音、带延迟的电子拨弦、低频脉冲。
- 每段尾音和混响绕回循环开头，Godot 开启整曲循环。
- 默认播放音量 35%，底部「音乐设置」可暂停或调节；设置存于本机 `user://audio.cfg`，独立于战役存档。

生成源码：`tools/compose_music.py`。使用 Python 3、numpy 与支持 Vorbis 编码的 ffmpeg 重建；玩家运行游戏不需要这些工具。

本配乐与生成源码可随本游戏使用、修改和分发。
