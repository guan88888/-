# 星门纪元：银河分裂

科幻战略桌游 · 单人战役与真人直连单挑 · Godot 2D

## 启动

1. 使用 Godot 4 打开根目录 `project.godot`，等待首次字体导入。
2. 按 F5 运行。已经在本机 **Godot 4.7.2 / Apple M1 / Compatibility** 实测。
3. 如果编辑器提示脚本被外部修改，选择重新加载。

Mac 也可以在 Finder 中双击根目录的 `启动游戏.command`，直接打开独立游戏窗口，不经过编辑器的调试选择模式。启动器会查找“应用程序”或“下载”里的 Godot.app；首次解压会先导入本地字体，不下载任何内容。

### 按钮完全没反应时

Godot 运行窗口顶部的 **「输入 / 2D / 3D」不是切换游戏画面类型**。「2D」「3D」会关闭游戏输入，供开发者点选节点；玩游戏请选 **「输入」**。此前截图选中的是「2D」，因此所有按钮都无法接收点击。项目仍然是 2D 游戏，选择「输入」不会改变画面。

脚本更新后请 F8 停止、重新加载外部修改，再按 F5。如果按钮呈灰色，检查旁边的解锁条件；例如「银河重整」第 4 轮才能使用。独立启动器也可避开编辑器拦截输入的问题。

单人战役无需账号或网络；真人单挑使用 ENet UDP 直连。字体和字体许可随项目提供，无外部素材下载。

## 深蓝舰桥界面

开场包含「星门纪元 / 银河分裂」、地图代码和三张阵营卡。桌面战局首屏按“顶部资源 HUD → 左侧星图 → 右侧战术指令 / 技能 / 行动序列 / 结束本轮”组织；右侧栏独立滚动。外交频道、舰队工坊、存档、星球信息、太空舰队、星门管理和战报位于星图之后。窄屏自动恢复为单列纵向排列。

桌面开场采用双栏，标题、地图代码、模式和三个阵营在首屏展示；「开启星门 / 新手教学 / 读取本地战役」固定在底部。窄屏自动改为单栏，长内容可滚动，底部按钮始终可见。沙盒的额外设置也可滚动查看。星图同时按可用宽、高等比例适配，初始视图完整显示全部星球；缩放窗口不会重置战局。若仍显示旧的大标题页面，先按 F8 停止，重新加载外部修改的脚本，再按 F5。

主色为近黑深蓝（#061326），面板采用海军蓝，钢青色仅用于主要操作、细线和选中状态。阵营使用三个独立线条徽记与扁平选择行；标题、按钮与资源栏收紧。桌面战局采用“顶部资源 HUD + 左侧大星图 + 右侧战术栏”的地图优先排版，右栏可独立滚动；外交、工坊、存档和详情等低频面板放在星图之后。窄屏保持单列纵向流。减少粗体、大面积亮色、圆角和重复标语。

星图采用平面战术符号：深色星球、首都双环、目标框选、细航线与稀疏星点，移除球体高光和层叠光晕。边缘坐标刻度随平移和缩放对应实际星图位置；旧情报保留暗色与斜线标记。阵营和危险状态仍用少量不同颜色辨识。全部由 Godot 原生绘制，无需联网下载美术资源。旧存档中的自定义舰队涂装保留。

## 每个按钮的说明

底部「音乐设置」可开关原创背景音乐《深蓝守望》、调整音量。配乐为 80 秒深空氛围循环，已随项目离线打包，默认音量 35%；切换页面、重开战役连续播放，开关与音量在下次启动时保留。

- 普通按钮下方直接显示用途或消耗；阵营卡、指令卡、模块开关旁显示对应说明。
- 鼠标悬停可看详细用途、条件和风险；键盘聚焦按钮后按 F1 也能查看。
- 屏幕底部和弹窗底部都有「？ 说明模式」。开启后点任意游戏控件只打开说明，不执行操作、不扣资源；灰色未解锁按钮也能查看条件。
- 点击「收起说明」返回原画面，原弹窗和未提交的文字保留；点击「返回操作」退出说明模式。说明模式中仍可滚轮或触摸滑动页面。
- 下拉框、自动存档开关、模块、涂装、拆分滑块及数量输入也有说明。确认按钮显示当前操作的具体后果，删除和覆盖会明确提醒。

说明画面见 `artifacts/09-button-help.png` 和 `artifacts/10-mobile-help.png`。首次使用说明模式后，请点「返回操作」再继续游戏。

## 上手操作

- **扩张**：点击指令，再点击与己方驻军通过开放星门相连的无主星球。
- **指令反馈**：选择战术或阵营技能后自动回到星图，目标高亮；进攻状态下先点己方星球也可以选择攻击编队。
- **进攻**：先选己方星球 / 舰队，再选进攻目标；确认突袭、围困、封锁、轰炸、策反或诱敌。
- **增援**：选择增援，再点击己方星球。
- **舰队调度**：选中驻军后，星球旁显示舰队图标；拖动它到星球、太空、舰队或星门。松手只打开菜单，确认后才扣资源。
- **舰队标记**：标记尺寸放大约两倍，点击范围同步扩大；驻守舰标与星球留出间距，选中舰队名称与兵力显示在星图左上角，保留旧情报的空心标记。
- **太空舰队**：可自由拖动；友军相遇可合并、支援、交换模块。远距离目标先选择「移动到附近」。
- **拆分**：舰队操作菜单内用滑块决定单位数。
- **地图**：拖动空白平移，滚轮 / 加减按钮缩放；触摸单指拖动，双指缩放；长按己方舰队打开菜单。
- **长页面**：在地图外滚轮或触摸滚动。地图内部滚轮用于缩放。
- **取消**：关闭菜单或按 Esc，不消耗资源。

确认菜单显示距离、行动点、燃料、风险与到达时间。邻接星门移动最便宜；封锁或损坏线路不可用。普通舰队进行非相连远程攻击需要 LV.2，突击 / 劫掠 / 侦察舰队可直接使用。敌控空间存在途中拦截风险，隐匿模块可避开。

## 规则

每轮基础 2 次行动，**战争周期默认 12 轮**，并不是每轮 12 次行动。结束本轮后结算领地产出、AI 行动、战争事件与外星威胁。

六种舰队：突击、守卫、开拓、劫掠、侦察、运输。工坊可以购买、升级、改名、换类型 / 图标 / 涂装和装配模块。每队有限模块槽，高级模块需 LV.2，最高 LV.5。升级可选择攻击、防御、速度、星门效率、远程攻击、侦察、运输、维修、撤退、威慑十种专精。

运输舰或装备运输模块的舰队可以装卸信用、材料、情报、燃料。物资装载时离开储备，被击毁会丢失；敌军可以拦截太空运输路线。维修恢复受损单位，不会无限生成新舰船。

帝国防守 +1，联盟开局多一颗星球并有生产优势，混沌进攻平局获胜。每个阵营有每轮一次主动技能；第 4 轮解锁一次性的银河重整。

外交每轮一次，包含结盟、停战、赠送、资源交易、交换情报、请求援军、通行、保护、共同抗敌、领地交换和背叛。好感范围 -100 到 100。联盟 / 停战会真实阻止攻击；不稳定领地可能叛乱。

## 侦察、指挥官与剧情

所有模式默认启用战争迷雾。星球坐标与开局归属来自旧航图；看不到的区域不会自动更新驻军、舰队位置和领土变化。暗色星球和空心舰标表示历史情报，`?` 表示未识别兵力。旧情报仍可用于计划进攻，但不能直接攻击已失去信号的舰队。

普通舰队在 155 范围发现信号，己方星球在 170 范围以及相邻星门提供基础观察。侦察舰或侦察模块可在 310 范围发现舰队、230 范围识别兵力；侦察专精每级增加 60。选中侦察舰后点击星图下方「主动扫描」，消耗 1 行动 / 2 情报，完整扫描 420 范围并持续至下一轮。扫描会暴露自己的信号。隐匿舰需要详细侦察才能发现。

「外交、交易与协议 → 交换情报」花费 2 材料，获得 4 情报及对方领地、已观察区域的报告。报告标注获取轮次，不会持续追踪。进攻预览、舰队列表、战报和回放均遵守玩家的可见信息；实际提交进攻会建立当地战斗接触。

三位指挥官使用不同决策优先级，每轮至多两次行动，出击、增援与建设都由自己的储备支付：

| 指挥官 | 偏好 | 外交差异 |
|---|---|---|
| 帝国 · 林铎 | 优先加固受威胁边境及首都，保守选择战力优势 | 结盟需好感 ≥0 |
| 联盟 · 沈遥 | 优先资源星与贸易，好感良好时提出停战 | 结盟需 ≥-25，交易需 ≥-40 |
| 混沌 · 乌隼 | 优先薄弱敌星、运输舰和暴露的太空舰队 | 结盟需好感 ≥15 |

结束回合后会打开「战况回放」，依次展示已观察到的移动、接触、交战和领土变化。支持上一个 / 下一个事件、自动播放、跳过；星图下方可重新打开最近一轮。回放读取历史星图，不重复结算资源；移动、炮火、占领使用简短的 2D 动画。

「战役事务」提供难民、工程师、叛逃舰队及追踪识别码等分支。选项直接显示费用与结果；资源不足时不会执行。第 2 轮起出现难民事件，第 4 轮根据是否接纳进入工程师或抗议支线；第 5 轮叛舰事件，第 7 轮出现对应后续。暂时关闭不会自动替玩家选择，也不会丢失事件；未处理时暂缓后续事件。接收叛舰会让己方太空舰队更容易被附近敌军拦截，后续可支付情报或燃料解除风险。

## 九种模式

| 模式 | 目标 |
|---|---|
| 标准银河战争 | 控制全部首都，或周期结束积分最高 |
| 外星入侵 | 第 3 / 5 / 7 轮出现入侵核心；摧毁三个核心并清除全部外星舰队 |
| 星门争夺 | 率先控制 5 座星门 |
| 护航运输 | 曙光运输船抵达标注终点；先占领终点才能驻守 |
| 残局生存 | 低资源、每轮敌军增强；守住首都到第 10 轮 |
| 外交竞赛 | 达到 180 外交积分；超时按战役积分结算 |
| 随机灾变 | 每轮发生灾变，周期结束比较积分 |
| 沙盒 | 调整资源、单位数、入侵概率、好感与回合记录长度，不强制结束 |
| 连续战役 | 断线航道 → 边境撤离 → 归航之战，三章保留幸存舰队 |

连续战役在开场的模式列表选择。第一章限 6 轮，占领熔炉并守住一轮；也可护送「远航补给船」到熔炉提前完成。第二章守住己方首都至第 6 轮；第三章限 10 轮，夺取任意敌方原始首都。每章失败后需读档或重开，不能直接跳关；胜利结算中点击「进入下一章」。

换章保留幸存舰队的舰名、单位、等级、模块、专精、涂装、货物及损伤，保留资源与已完成剧情选择；重建当地星图、外交和侦察信息。每章补充 6 燃料。第一章救下补给船，第二章另获 12 信用 / 8 材料 / 8 燃料；工程师支援可在后续换章时增加 3 材料。

## 存档

提供三个手动槽、独立自动槽、存档时间、覆盖 / 读取 / 删除确认。自动保存发生在新局与每次成功行动后，可关闭。存档包含所有星球、舰队、模块、坐标、外交、资源、事件和随机数状态，读档后随机过程仍可重现。

当前存档版本为 3，新增可选 `frontier` 字段保存家园、机库、等级、星级、福利、卡池保底、副本与功勋；读取旧存档时补齐新增字段。另保存迷雾历史、扫描有效期、指挥官、最近一轮回放、剧情分支和连续战役进度。可读取本项目版本 2 的完整战役存档：加载时补齐新字段，不重置领地、舰队或资源；未保存前不会改写原文件。更早的残缺存档仍不转换。

Godot `user://` 下的文件：

- `campaign_slot_1.json`、`campaign_slot_2.json`、`campaign_slot_3.json`
- `campaign_auto.json`

Mac 默认位于 `~/Library/Application Support/Godot/app_userdata/星门纪元：银河分裂/`。旧版 `star_gate_save.json` 保留不动；它缺少完整战局数据，不能作为新版战役导入。

## 远征、家园、战舰与真人单挑（新增）

开场页「银河中心」提供家园、副本、抽奖、战舰、福利五个自绘图标入口，点击后会直接创建当前选择的战役并打开对应分区；战役顶部仍保留「远征与家园」入口。家园包含指挥中心、合金矿场、能源阵列、贸易港四类建筑，升级消耗行动点、星币和材料，并在每轮自动生产资源。副本包含「遗迹回收」「星门突袭」「深空堡垒」，使用当前出战战舰挑战，按战力与随机波动结算材料、星币和阵营功勋；副本次数每轮恢复 3 次。

战舰图鉴包含曙光级护卫舰、星尘级侦察舰、苍穹级巡洋舰、深渊级战列舰。每艘战舰有 1–5 级和 0–5 星，玩家可以通过抽奖、建造或星币直购获得战舰，升级等级，选择出战并部署到己方首都；抽到重复舰体会自动升星，5 星后仍会增加库存。补给系统包含标准补给、精英舰队补给、工程材料补给三个卡池，分别支持单抽与十连，价格和 SSR/SR/R/材料概率不同；每个卡池共享 SSR 20 抽保底。

福利中心按轮次提供每日签到、舰队援助和远征里程奖，奖励包含星币、材料、燃料和战舰；完成 3 次副本后可以领取远征里程奖。星币可以来自副本、福利、家园贸易港，也用于建筑升级、战舰建造、战舰直购和抽奖。

「真人联网单挑」使用 Godot ENet UDP：房主输入端口创建房间，挑战者输入房主 IP、相同端口和口令加入。双方可选择帝国、联盟或混沌，使用独立的 1v1 旗舰战斗：主炮、重型鱼雷、防御、维修、一次性阵营绝技和投降；房主权威结算回合、护盾、血量和胜负。局域网直接填写房主 IP；跨网需要公网 UDP 端口映射或同一虚拟局域网。战役资源和抽奖库存不会带入真人对局。

新系统验证：

```sh
Godot --headless --path . --script res://tests/frontier_cases.gd
Godot --path . --script res://tests/frontier_ui.gd
python3 tools/test_network.py /path/to/Godot
```

联机测试在同一台电脑启动两个独立进程完成，覆盖真实 UDP 连接、状态同步、口令拒绝与断线；尚未进行跨公网或手机真机联机验证。默认 UDP 端口是 24560。这里新增的是独立真人旗舰单挑，银河战役仍为单人模式。
