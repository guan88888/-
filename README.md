# 星门纪元：银河分裂

一款只有前端、无需联网的单人桌游。直接双击 `index.html` 即可开始。

## 玩法

- 选择残余银河帝国、自由星域联盟或破碎星域议会。
- 每轮行动两次，只需选择扩张、进攻或增援。
- 首次开局提供四步新手教学，并可在游戏内随时重播。
- 每个阵营拥有常驻被动、每轮主动技能、核心机制、第四轮终极技能和明确弱点。
- 每局根据星图代码随机生成首都、舰队与事件顺序。
- 夺取敌方首都立即获胜；否则第 12 轮按控制星球数量结算。
- 每轮可选择与另一个势力结盟，结盟双方不会互攻，并共同抵抗外星系。
- 每轮有 25% 概率触发外星系入侵，外星舰队会占领无主星球并攻击边境。

## 文件

- `index.html`：页面结构
- `styles.css`：科技战争终端风格与响应式布局
- `game.js`：全部规则、随机生成、AI 与事件系统

项目不包含远程字体、分析脚本、图片或第三方依赖，可完全断网运行。
